# 常見問答（FAQ)

## 費用與門檻

### Q：要花多少錢？

全部免費。Cloudflare Workers 免費方案即可（Queues 自 2026 年 2 月起開放免費方案），Meta API 免費，本專案 MIT 授權。唯一可能的費用是你的量真的很大（每天數千則命中留言）才需要升級 Workers Paid（約 USD 5/月）。

### Q：我不會寫程式，裝得起來嗎？

可以。部署走「Deploy to Cloudflare」按鈕、管理者帳號在網頁表單建立、日常操作全在管理後台——整個流程唯一像「技術活」的是到 Meta 開發者後台抄貼幾個設定值，照著[部署教學](../README.md)一步步做即可，全程不需要打開終端機。

### Q：一般個人 IG 帳號可以用嗎？

不行，Meta API 要求 **Instagram 專業帳號**（商業或創作者）。在 IG App 的設定裡可以免費切換，一分鐘完成。

### Q：需要自己買網域嗎？

不用。部署後 Cloudflare 會給你一個 `*.workers.dev` 網址，webhook 與管理後台都能直接用。要綁自訂網域也支援，但非必要。

## 安全與合規

### Q：這會不會違反 Instagram 規定、被封號？

本專案只使用 **Meta 官方 API**（不是瀏覽器模擬、不是私有 API 爬蟲），只回覆「主動在你貼文留言／回應你限動」的使用者，不主動騷擾、不群發、內建每分鐘/每日發送上限與熔斷保護——這正是 Meta 官方開放這組 API 的用途（ManyChat 等服務同一套 API）。遵守常識性使用（不要設定誘導濫發的內容）風險很低。

### Q：我的 token、密碼、資料存在哪裡？安全嗎？

全部在你自己的帳號裡：機密（token、App Secret）存 Cloudflare Secrets，資料（留言紀錄、發送紀錄）存你自己的 D1 資料庫，程式碼在你自己的 GitHub 複本。沒有任何第三方伺服器經手。後台登入有密碼雜湊（PBKDF2）、CSRF 防護與頻率限制；webhook 有簽章驗證。

### Q：Meta App 需要通過 App Review（應用程式審核）嗎？

不用。App Review 是要服務「別人的 IG 帳號」才需要的流程；自用工具操作自己授權的帳號，標準存取即可。但 App 必須切換為「**發佈**」（上線）狀態——否則陌生人的留言不會觸發 webhook（開發模式只送 App 成員的事件）。

## 功能

### Q：支援哪些自動化？

1. **貼文/Reels 留言**：命中關鍵字 → 公開回覆＋私訊
2. **限時動態回應**：訊息含關鍵字 → 私訊（逐則限動設定）

不支援：一般 DM 自動回覆（非限動回應的私訊）、多步驟對話流程（flow builder）、主動群發。

### Q：同一個人留言兩次會收到兩次私訊嗎？

防重複的單位是「留言」：**每一則留言**最多一次公開回覆＋一次私訊，Meta 重送 webhook 也不會重發。但同一個人在**兩篇貼文**（或同一篇留兩則命中的留言）會各觸發一次——這是刻意設計，否則他想索取第二篇的連結會拿不到。

### Q：關鍵字要注意大小寫或繁簡體嗎？

不用。比對前會自動正規化：英文大小寫、全形半形、繁體/簡體互通（寫「錢包」，留言「钱包」也會觸發），多餘空白也會處理。

### Q：還沒發布的排程貼文可以先設定嗎？

可以，這是「**待命自動化**」：先把關鍵字與回覆設定好並啟用，下一篇新貼文（含排程貼文上線）會自動接上，連發布後的第一則留言都不會漏。另有「全帳號預設」可套用到所有沒有專屬設定的貼文。

### Q：可以只私訊、不公開回覆嗎？

可以，兩個開關獨立。限動自動化則本來就只有私訊（限動沒有留言串）。

### Q：回覆速度多快？

通常留言後數秒內完成公開回覆與私訊（webhook 即時觸發，經佇列處理）。Meta API 偶發性錯誤時會自動重試（30 秒/2 分/10 分）。

### Q：可以管理多個 IG 帳號嗎？

目前不行，本專案定位是單一帳號自用工具。要管多個帳號可以各部署一套（免費方案可部署多個 Worker）。

## 維運

### Q：部署好了但留言沒反應，怎麼排查？

依序檢查：
1. Meta App 是否已切換為「**發佈**」狀態（最常見的原因）
2. Webhook 是否驗證成功、已勾 `comments` 欄位
3. 後台該貼文的自動化是否「啟用中」（縮圖右上角開關為綠色）
4. 後台首頁是否出現「熔斷器已自動開啟」警示（按熔斷復歸）
5. 執行 `npm run check-meta` 檢查 token 健康度

### Q：「熔斷器已自動開啟」是什麼意思？

系統偵測到 Meta API 連續失敗（例如 Meta 端暫時故障）時，會自動暫停所有發送以保護你的帳號，不是你誤觸。確認 IG 正常後到後台按「熔斷復歸」即恢復；若 Meta 持續出錯它會再次開啟。

### Q：Access token 會過期嗎？

會（長效 token 約 60 天）。系統每日排程會檢查 token 健康度並在到期前提醒；到 Meta 後台重新產生、更新到 Cloudflare Secrets 即可（更新後約 30 秒生效）。

### Q：忘記後台密碼怎麼辦？

沒有「忘記密碼」流程（單人自用工具的取捨）。密碼遺失需要清掉資料庫的管理者資料重建，等同重新初始化，請妥善保管。

### Q：原作者更新了新功能，我要怎麼跟上？

一鍵部署建立的是你自己的複本，**不會自動同步**上游更新。手動同步：

```bash
git remote add upstream https://github.com/pjwang2022/instagram-comment-dm-bot.git
git fetch upstream && git merge upstream/main && git push
```

push 後 Cloudflare 自動重新部署（部署指令已含資料庫 migrations）。

## 比較

### Q：跟 ManyChat 這類服務差在哪？

| | 本專案（自架） | ManyChat 等 SaaS |
|---|---|---|
| 費用 | 免費 | 月費制（依聯絡人數成長） |
| 資料 | 全在你自己帳號 | 存在服務商 |
| 功能 | 留言/限動關鍵字 → 回覆＋私訊 | 多步驟 flow、廣播、CRM 等 |
| 維護 | 自己負責（更新靠 merge） | 服務商維護 |

適合「只需要留言自動回覆＋發連結」的創作者；需要複雜對話流程或行銷漏斗的話，SaaS 仍是較省事的選擇。
